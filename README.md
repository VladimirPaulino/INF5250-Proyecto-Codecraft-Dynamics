**Nombre y descripcion breve del sistema (MVP Inicial):**

AutoPark. Un sistema de parqueos, donde un usuario final podra reservar tickets para reservar parqueos, al mismo tiempo la administracion podra monitorear todo el que entra y sale del parqueo.

**Lenguaje de programación, framework y motor de base de datos utilizado.**
Javascript, Knex.js, HTML,CSS, Node.js

Guía de Configuración

1. **Instalar dependencias**

```bash
   npm install
   ```

2. **Configurar base de datos** - Actualiza `database/db.config.js` con tus detalles de conexión MySQL
3. **Crear base de datos**

```bash
   npm run db:create
   ```

4. **Verificar conexión**

```bash
   npm run db:check
   ```

5. **Ejecutar migraciones**

```bash
   npm run migrate
   ```

6. **Iniciar servidor**

```bash
   npm start
   ```
